# gleipnir-sdk

Verifiable action records for AI agents: record each tool call with the real outcome in the external system, sign and chain it, anchor it outside your infrastructure, and export bundles your buyer can verify offline.

```bash
pip install gleipnir-sdk
```

It also installs `gleipnir mandate`, the command line for Gleipnir mandates (spec 0.5 draft, 0.4 objects still
accepted): keys, mandates, payee approvals, payments, checks as a bank would, overrides, revocations, a reference HTTP
checker (`serve`) and an MCP server for agents (`mcp`).

See https://github.com/getgleipnir/gleipnir for the quickstart.
