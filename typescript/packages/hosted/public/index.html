Gleipnir sandbox checker

SANDBOX. Test checker for pilot partners. Not for real money.

Know Your Agent for bank transfers: before a platform sends a transfer an AI agent started, it asks this checker whether a company signatory's signed mandate covers it, and gets back a signed allow, block or escalate.

API: POST /v1/check, POST /v1/resolve, POST /v1/revoke, GET /v1/revocations, public keys at /t/<tenant>/keys. Access by API key only.
